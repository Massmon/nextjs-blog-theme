Netlify provides an all-in-one platform for deploying modern web projects. From automatic builds to serverless functions, Netlify simplifies the deployment process so you can focus on building great applications.

## Key features

- **Continuous deployment** — Automatically build and deploy when you push to Git
- **Serverless functions** — Run backend code without managing servers
- **Edge functions** — Execute logic at the network edge for low latency
- **Forms handling** — Collect form submissions without a backend
- **Identity** — Add authentication to your site with minimal setup

## Quick deploy steps

1. Push your project to a Git repository (GitHub, GitLab, or Bitbucket)
2. Log in to [Netlify](https://app.netlify.com) and click **Add new site**
3. Connect your repository and configure build settings
4. Netlify will automatically build and deploy your site

Every push to your main branch will trigger a new deploy, and pull requests get their own preview URLs.
